# MyFlow: Plataforma de Automatización de Workflows  

<img width="699px" alt="image" src="https://github.com/user-attachments/assets/28c9f481-f92c-4627-826a-8482911898cb" />


Este repositorio contiene el prototipo inicial de una aplicación web para la automatización de workflows. Se concibe como una interfaz visual intuitiva que permite a los usuarios definir y gestionar sus propias secuencias de tareas automatizadas, incluyendo la creación e interacción fluida con bases de datos MySQL y bases de datos vectoriales lanzadas como servicios en Docker consumidas por servidores RAG desplegados en Go.
